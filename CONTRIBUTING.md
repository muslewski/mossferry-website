# Contributing to mossferry-website

This repository is the **marketing one-pager** for [`mossferry`](https://github.com/muslewski/mossferry).

## Where to file what

| Topic | Repo |
|---|---|
| Tool bugs, CLI features, install failures | **[mossferry](https://github.com/muslewski/mossferry/issues/new/choose)** |
| Questions & ideas about the tool | **[mossferry Discussions](https://github.com/muslewski/mossferry/discussions)** |
| Website copy / layout / performance | Issues on **this** repo |

## Dev (website)

```bash
npm install
npm run dev      # Vite
npm run build
```

Please keep product install commands accurate (`npm install -g mossferry` / `npx …`).
