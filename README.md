# mossferry website

Public marketing one-pager for **[mossferry](https://github.com/muslewski/mossferry)**.

- **Live:** https://mossferry.muslewski.com
- **Stack:** Vite static site (Round 7 — responsive + fast media)
- **Product repo:** https://github.com/muslewski/mossferry

## Develop

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Deploy

Vercel project linked to this repo. Production domain: `mossferry.muslewski.com`.
